JDK and UCD Agent Upgrade – Daily Server Patching Plan (ISD)

Prepare and coordinate a phased patching schedule for the identified ISD server inventory.

The activity will be divided into daily execution batches, with specific server IPs assigned to each day to ensure controlled upgrades, effective coordination with OS, and sufficient time for post-upgrade validation.

**Required planning:**
- Identify and allocate target server IPs across the planned execution days.
- Define the daily patching sequence and required OS support.
- Account for server availability and operational dependencies.
- Perform post-upgrade version and service validation for each batch.
- Document completed IPs, pending servers, and any exceptions.





JDK and UCD Agent Upgrade – Daily Production/DR Patching Plan (Digital)

Prepare a phased, day-by-day patching schedule for the identified Digital Production and DR servers required for the subsequent Production-to-UAT cloning activities.

Specific server IPs will be allocated to each execution day, allowing the upgrades to be performed in controlled batches while coordinating the required OS support and minimizing operational impact.

**Required planning:**
- Identify and allocate Production and DR server IPs across the planned execution days.
- Define daily execution batches and required OS support.
- Coordinate appropriate maintenance windows.
- Validate JDK and UCD Agent versions following each batch.
- Track completed servers, outstanding IPs, and exceptions.
