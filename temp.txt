JDK and UCD Agent Upgrade – Environment-Wide Server Patching

Coordinate and execute the required JDK and UCD Agent upgrades across the identified server inventory (approximately 100 servers).

The activity involves coordinating with OS and relevant application teams to establish execution batches, confirm server readiness, and perform the upgrades with appropriate post-upgrade validation.

This activity is part of the broader JDK and UCD Agent patching initiative and will be coordinated with the related Digital server upgrade requirements to maintain a consistent execution approach.

**Scope:**
- Validate the target server inventory and current installed versions.
- Coordinate patching windows and execution batches with OS.
- Upgrade UCD Agents and JDK versions as applicable.
- Perform post-upgrade service and version verification.
- Document completed servers, outstanding dependencies, and any exceptions.





JDK and UCD Agent Upgrade – Digital Production and DR Servers

Coordinate the required JDK and UCD Agent upgrades on the identified Digital Production and DR servers, which are required to support the planned server cloning and UAT preparation activities.

The upgrades will be coordinated with the broader server patching initiative to ensure consistent execution, version alignment, and appropriate validation across the environments.

**Scope:**
- Confirm the target Production and DR server inventory.
- Coordinate execution windows and required OS support.
- Perform the applicable JDK and UCD Agent upgrades.
- Validate installed versions and service availability following the upgrades.
- Confirm readiness for the subsequent Production-to-UAT cloning activities.
