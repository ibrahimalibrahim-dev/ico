UAT Validation – UCD Agent and JDK Upgrade Sequence

Validate the supported upgrade sequence for the UCD agent and JDK in UAT, in coordination with IBM support.

The following scenarios will be evaluated based on vendor guidance:

UCD agent first, then JDK: Upgrade the UCD agent, validate its operation, upgrade the JDK, and revalidate agent connectivity and deployment functionality.

JDK first, then UCD agent: Upgrade the JDK, validate compatibility with the existing agent, upgrade the UCD agent, and revalidate agent connectivity and deployment functionality.

For the selected approach, track execution, validation results, identified issues, and any required corrective actions. Confirm the final JDK version and supported configuration, and perform a follow-up Tenable scan to verify remediation of the identified vulnerabilities.

Completion criteria: Vendor-supported upgrade sequence confirmed, UAT validation completed, agent functionality verified, and Tenable findings reviewed before proceeding with production remediation.
